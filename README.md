# Portfólio | Diogo Rochembach

Portfólio pessoal e currículo online — Business Intelligence & Análise de Dados.

## Stack

- HTML5 estático
- [Tailwind CSS](https://tailwindcss.com) via CDN
- Google Fonts (Oswald + Inter)
- [Unicorn Studio](https://www.unicorn.studio) para o background animado

## Estrutura

```
.
├── index.html      # página única (hero, navegação e seções)
├── foto_diogo.jpg  # foto de perfil
└── README.md
```

## Rodando localmente

Não há build step. Basta abrir o `index.html` no navegador, ou servir a pasta:

```bash
npx serve .
```
